# Tools

**Nav landing:** [https://oinp.getnorthpath.com/tools/clb-converter](https://oinp.getnorthpath.com/tools/clb-converter)

**Nav:** Tools

Helper widgets that feed the same Workforce Priority grid. The nav item opens the **CLB converter**. CRS (federal Express Entry) is on GetNorthPath, not this grid.

---

## Tools on this site

| Tool | URL | What it does |
| --- | --- | --- |
| CLB converter | […/tools/clb-converter](https://oinp.getnorthpath.com/tools/clb-converter) | IELTS, CELPIP, PTE Core, TEF, TCF → CLB / NCLC, ability by ability, plus OINP language points |
| NOC and TEER finder | […/tools/noc-teer-finder](https://oinp.getnorthpath.com/tools/noc-teer-finder) | Search all 516 NOC 2021 unit groups; TEER and occupation points |
| Wage lookup | […/tools/wage-lookup](https://oinp.getnorthpath.com/tools/wage-lookup) | Median wage by occupation and region; wage-point context; Job Bank links |
| Tax bracket estimator | […/tools/tax-bracket-estimator](https://oinp.getnorthpath.com/tools/tax-bracket-estimator) | Hourly / weekly / monthly pay → annual figure and OINP tax-history band |

**Language notes (CLB page):** OINP accepts IELTS General Training, CELPIP General, and PTE Core for English; TEF Canada or TCF Canada for French. Academic tests are not accepted. Results must be less than 2 years old. Language points use the **lowest** of the four abilities.
