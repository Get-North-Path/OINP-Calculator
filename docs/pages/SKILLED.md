# Skilled TEER 0 to 3

**Live:** [https://oinp.getnorthpath.com/calculator/skilled-teer-0-3](https://oinp.getnorthpath.com/calculator/skilled-teer-0-3)

Dedicated calculator for an eligible Ontario **job offer** in management, professional, or technical work (**NOC TEER 0, 1, 2, or 3**).

---

## What is different from the hub

- Applicant type is locked to **worker**
- TEER choices are 0 to 3 only (mismatch warning if the NOC is 4 or 5)
- Max score **130**, including TEER points (9 or 6)
- Copy and FAQ are written for this pathway (Job Offer ID, employer-first flow)

Typical language floor: **CLB 6** ( **CLB 5** for listed trades). Confirm on ontario.ca.

TEER 0 to 3 nominees can often use **Express Entry**; an accepted nomination adds **600 CRS**.
